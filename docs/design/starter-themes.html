The research draft had 14. "Beauty" is folded into Joy so that every theme has its own color. Taking care of things is deliberately stone grey: bills and upkeep get an honest home without competing with the themes a person chose.

How color works

Each theme now stores its own color. Until now the color came from a hash of the name, so two themes could land on the same color. A new theme, or one a person types themselves, gets the first palette color that none of their themes uses yet, so up to 12 themes never share a color. A person can also pick a theme's color.

Every color is at least 5.4:1 against the paper page and 9:1 against the dark page, above the 4.5:1 that body text needs. Colors stay as marks and words (Decision 060), never page grounds.

Your themes today

Nothing you already named changes. "Time with my kids", "Great meals" and "Being outside" keep their names and memos, and each gets its own color from the palette. Where your name matches a starter theme, as Great meals does, it takes that theme's color.

Yours to choose

1. The set

Keep these 13, change any name or meaning, or add or drop themes. Do you want "Beauty" back as a 14th theme?

2. The first-run question

The proposed prompt reads "Which of these sound like you?", above the list with every theme unticked. Or should all of them start ticked, so a person only removes what doesn't fit?

3. Taking care of things

Should it be offered at first run like the others, or start hidden and appear only when a person reaches for it?
